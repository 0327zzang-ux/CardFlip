# 🎴 CardFlip : 차세대 인터랙티브 3D 디지털 명함 서비스 (Processing 4 Hybrid)

> **수업 과제 프로토타입에서 실제 배포(Production MVP) 수준으로 완성된 차세대 인터랙티브 3D 디지털 명함 웹 서비스**  
> **기술 스택**: Vite + React 19 + TypeScript + Three.js + Tailwind CSS v4 + Processing 4 (Java 런처 호환)

---

## 📌 1. 프로젝트 소개

**CardFlip**은 평면적인 종이 명함과 단순 2D 링크트리의 한계를 극복하고, 사용자의 다양한 페르소나를 감각적인 3차원 실물 카드로 표현하는 인터랙티브 명함 서비스입니다.  
실제 메탈·유리·홀로그램 카드를 손에 쥐고 만지는 듯한 **3D 물리 관성 회전 및 단일 탭 수직 정렬**, **2-Layer 물리 메커니즘을 적용한 2축 크로스 캐러셀 바텀 시트**, **1:1 실시간 손가락 트래킹 및 50% 임계값 스냅 인터랙션**, 그리고 고유 URL(`/?u=minsu_design`)과 **스마트폰 기본 카메라로 인식하는 실시간 QR 교환 시스템**을 제공합니다.

## ✨ 2. 핵심 인터랙션 & 기능

### 1) 홈 화면 : 3D 대표 명함 단독 스테이지
- **세로 폰 최적화 90° 시계방향 회전 텍스트**: 스마트폰을 세로로 쥐었을 때 가로 명함이 가장 크고 시원하게 보이도록 배치
- **물리 관성 회전 (Inertia & Deceleration)**: 스와이프한 속도를 반영하여 손을 떼도 카드가 잔여 속도로 더 돌다가 감속비(`0.94`)에 따라 서서히 멈춤 (멈춘 각도 그대로 유지)
- **단 한 번의 터치로 똑바로 정렬 (Single Tap Align)**: 카드가 어느 각도로 삐뚤어져 있든 한 번만 가볍게 탭하면 X축 틸트를 완전 제거하고 앞면(0°) 또는 뒷면(180°)으로 수직 똑바로 정렬
- **정면 최적화 조명 시스템**: 전방향 환경광 + 듀얼 정면 키라이트로 그늘이나 눈부신 글레어 없이 환하고 또렷한 가독성 확보
- **대표 명함 1장 단독 고정**: 홈 화면에서는 좌우 스와이프로 명함이 바뀌지 않으며, 대표 명함 1장만 단독 표시 (명함 교체는 바텀 시트에서만 수행)
- **하단 컨트롤러**: 하단 정중앙 QR 버튼 + 최하단 바텀 시트 제스처 핸들

### 2) 바텀 시트 : 2축 크로스 캐러셀 & 2-Layer 물리 도크
- **순수 미니멀리즘**: 프레임 박스 완전 삭제, 모든 안내 문구(`상하 스와이프`, `좌우 스와이프`) 및 카드 위 메타 아이콘 완전 배제
- **2D 정면 투명 명함 (`Card2DTransparent`)**: 틸트/회전 없는 정면 2D 뷰, 텍스트와 테두리 외 100% 투명
- **2-Layer 물리 메커니즘**:
  - 뒷단 (Layer 1): 중앙 도크에 고정된 2D 순수 컬러 스킨 플레이트
  - 앞단 (Layer 2): 투명 명함 수평 트랙
  - 상하로 스와이프 시 스킨이 실시간 전환되어 명함에 투영되며, 좌우로 다른 명함을 넘겨도 현재 선택된 스킨이 중앙 도크에 유지되어 새로 들어온 명함에 연속 투영
- **명함 순서 체계**: `0 (새 명함 제작)` — `1 (대표 명함)` — `2 (명함 2)` — `3 (명함 3) ...`
  - 명함 목록은 우측으로만 선형 스택되며, 우측 다음 명함의 일부(~40px)가 살짝 노출(Peek-in)되어 수평 캐러셀을 암시
  - 대표 명함(1번)에서 좌측으로 스와이프하면 `0번 [+ 새 명함 제작]` 슬롯 노출
- **`[+ 새 명함 제작]` 슬롯 (0번)**: 명함 규격 투명 카드 중앙에 흰색 테두리 + 녹색 플러스(`+`) 아이콘 단독 배치 (터치 시 제작 모달 오픈, 신규 명함은 목록 맨 우측 끝 추가)
- **하단 2단 수직 버튼**:
  - 상단: `[★ 대표 명함으로 설정]` (탭 시 해당 명함을 1번 자리로 승격, 기존 대표는 우측으로 한 칸 이동) / `[★ 현재 대표 명함]` (1번 슬롯 시 활성 상태)
  - 하단: `[명함첩]` (상단 버튼과 완전히 동일한 크기 및 둥근 모서리 규격)
- **1.5초 롱프레스 제스처**: 1.5초 유지 시 카드 플로팅 → 좌우 드래그 시 순서 맞바꿈(Swap), 손을 떼면 편집 모달 오픈

### 3) 실시간 1:1 트래킹 & 50% 임계값 스냅
- **명함 수평 캐러셀**: 카드 폭 50% (`158px`) 기준 스냅 이동 / 스냅 백
- **스킨 수직 캐러셀**: 스킨 높이 50% (`50px`) 기준 스냅 장착 / 스냅 백
- **바텀 시트 열기/닫기**: 50% (`120px`) 기준 스냅 오픈 / 스냅 닫기 / 스냅 백
- **스마트 명함첩 드로어**: 50% (`140px`) 기준 스냅 닫기 / 스냅 백

## 🚀 3. 실행 방법 (Quick Start Guide)

### 방법 A. Processing 4 과제 평가 시연용 (원클릭 실행)

1. Processing 4 IDE에서 `CardFlip/CardFlip.pde` 파일을 엽니다.
2. 좌측 상단의 **재생(▶) 버튼을 클릭**합니다.
3. 내장 Java 웹서버가 가동되며 기본 브라우저에 최신 React 3D 명함 앱이 자동으로 열립니다.
4. 웹 코드 수정 후 Processing 반영이 필요할 때는 터미널에서 다음 명령어를 실행합니다:
   ```bash
   cd web
   npm run build:sync
   ```

---

### 방법 B. 모바일 Wi-Fi 접속 (스마트폰 현장 시연)

PC와 스마트폰이 **동일한 Wi-Fi**에 연결되어 있으면 스마트폰에서 실물 명함 앱처럼 직접 터치 제스처를 시연할 수 있습니다.

1. PC에서 개발 서버 실행:
   ```bash
   cd web
   npm run dev
   ```
2. 스마트폰 카메라로 `phone_connect_qr.png` QR 코드를 비추거나 브라우저 주소창에 아래 주소를 입력:
   ```text
   http://192.168.0.31:5173
   ```

## 🎮 4. 조작 가이드 (Controls & Shortcuts)

| 구분 | 조작 방법 | 기능 설명 |
| :--- | :--- | :--- |
| **3D 카드 틸팅/회전** | 마우스 / 터치 드래그 | 카드를 3D 공간에서 자유 회전 (손 떼면 관성 회전 후 서서히 정지) |
| **앞/뒷면 똑바로 정렬** | 단 한 번의 가벼운 탭 / 클릭 | 기울어진 각도 상관없이 X축 틸트 제거 후 수직 앞(0°) ↔ 뒷면(180°) 정렬 |
| **바텀 시트 열기** | 최하단 핸들 위로 드래그 / 탭 | 실시간 1:1 추적, 120px(50%) 이상 당기면 스냅 오픈 |
| **바텀 시트 닫기** | 최상단 핸들 아래로 드래그 / `[X]` | 실시간 1:1 추적, 120px(50%) 이상 내리면 스냅 닫기 |
| **명함 목록 둘러보기** | 바텀 시트 내 좌우 스와이프 | 158px(50%) 이상 드래그 시 다음/이전 명함 스냅 전환 (스킨 색상 유지) |
| **스킨 실시간 교체** | 바텀 시트 내 상하 스와이프 | 50px(50%) 이상 드래그 시 이전/다음 스킨 스냅 장착 |
| **대표 명함 승격** | `[★ 대표 명함으로 설정]` 탭 | 선택한 명함이 1번 대표 자리로 즉시 이동, 기존 대표는 우측 시프트 |
| **순서 맞바꿈 / 편집** | 중앙 명함 1.5초 롱프레스 | 플로팅 후 좌우 드래그 시 순서 변경, 손을 떼면 편집 모달 오픈 |
| **스마트 명함첩** | 하단 `[명함첩]` 버튼 | 교환된 명함 목록 확인, 소속/직무별 분류, 원클릭 연락처(.vcf) 저장 |
