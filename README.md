# 🎴 CardFlip : 차세대 인터랙티브 3D 디지털 명함 앱
> **인터랙티브 미디어 / 피지컬 프로그래밍 기말고사 프로젝트**  
> **실행 환경**: Processing 4 (Java) 기반 원클릭 하이브리드 구동

---

## 📌 1. 프로젝트 소개

**CardFlip**은 평면적인 종이 명함의 한계를 극복하고, 사용자의 다양한 페르소나를 감각적인 3차원 디지털 카드로 표현하는 인터랙티브 명함 애플리케이션입니다.  
실제 메탈·유리·홀로그램 카드를 손에 쥐고 만지는 듯한 **3D 물리 회전 및 양면 플립**, 상하좌우 **2축 제스처 내비게이션**, 웹캠을 통한 **실시간 QR/고유 ID 교환**, 그리고 수집된 명함의 **소속/직무 기반 자동 분류 명함첩**을 제공합니다.

> [!IMPORTANT]
> **무설치 원클릭 실행 보장 (Zero-Configuration)**  
> 복잡한 Node.js 설치, 빌드(`npm run build`), 데이터베이스 실행 없이 **Processing 4 IDE에서 스케치를 열고 재생(▶) 버튼을 누르면 즉시 전체 시스템이 구동**됩니다.

## ✨ 2. 핵심 기능 (Core Features)

1. **멀티 명함 제작 & 5종 3D 스킨 시스템**
   - 1인 다명함 지원 (학생용, 디자이너/개발자용, 개인 소셜용 등 자유롭게 생성/전환)
   - 5종 시그니처 머티리얼 스킨: `홀로그램 프리즘`, `무광 흑요석(Matte Obsidian)`, `글래스모피즘(Frost Glass)`, `사이버펑크 네온`, `샴페인 골드`
2. **감각적인 3D 물리 인터랙션 & 양면 기록**
   - 마우스 드래그로 360° 자유 틸팅 및 관성 스핀(Damping)
   - 더블 클릭 또는 플립 버튼으로 180° 반전 (앞면: 핵심 프로필 / 뒷면: 포트폴리오 바이오 및 링크)
3. **2축 제스처 내비게이션**
   - **X축 (좌 / 우 스와이프 및 방향키 ← / →)**: 보유한 내 다른 명함으로 전환 및 끝단에서 [+ 새 명함 만들기]
   - **Y축 (상 / 하 스와이프 및 방향키 ↑ / ↓)**: 수집한 스킨을 현재 명함에 실시간 롤링 적용
4. **원클릭 스마트 하이퍼링크**
   - 명함에 포함된 GitHub, Notion, LinkedIn, Portfolio, Instagram 주소를 클릭하면 새 창으로 즉시 이동
5. **실시간 QR 스캐너 & 고유 ID 원터치 교환**
   - 웹캠을 활용한 실시간 QR 코드 스캔 및 고유 식별자(`@ID`) 검색 교환
   - 웹캠이 없거나 권한 차단 환경을 대비한 **[1초 테스트 QR 자동 인식]** 버튼 제공
6. **소속 / 직업별 지능형 자동 분류 명함첩**
   - 햄버거 메뉴(☰)를 누르면 교환된 명함이 회사·학교별, 직군(디자인/개발/기획 등)별로 자동 클러스터링되어 정리

## 🚀 3. 빠른 시작 및 실행 방법 (Quick Start Guide)

평가자(교수님 / 조교님)를 위한 무설치 원클릭 실행 절차입니다:

```
[1단계] Processing 4 실행
   ↓
[2단계] 메뉴에서 [파일] -> [열기] 선택 후 'CardFlip/CardFlip.pde' 파일 선택
   ↓
[3단계] 좌측 상단의 재생(▶) 버튼 클릭!
   ↓
[4단계] Processing 대시보드 창이 뜨면서 기본 웹 브라우저가 자동으로 열립니다.
```

*브라우저가 자동으로 열리지 않을 경우: Processing 창의 **[브라우저 다시 열기]** 버튼을 누르거나, 웹 브라우저 주소창에 `http://localhost:8080/`을 직접 입력하세요.*

### 📱 스마트폰으로 실물 시연하는 방법
1. 컴퓨터와 스마트폰을 **동일한 Wi-Fi**(또는 스마트폰 핫스팟)에 연결합니다.
2. Processing 4 실행 창에 표시되는 **"스마트폰 접속용 안내 QR 코드"**를 스마트폰 기본 카메라로 비춥니다.
3. 폰 브라우저가 열리며 터치 드래그, 자이로스코프(기울기) 틸팅 효과를 스마트폰 화면에서 직접 체감할 수 있습니다!

## 🎮 4. 조작 가이드 (Controls & Shortcuts)

모바일 터치 스와이프와 데스크톱 마우스/키보드 조작을 완벽하게 지원합니다:

| 구분 | 조작 방법 | 기능 설명 |
| :--- | :--- | :--- |
| **3D 카드 틸팅** | 마우스 클릭 & 드래그 | 카드를 3차원 공간에서 360도 자유자재로 회전 |
| **앞/뒷면 뒤집기** | 카드 더블 클릭 또는 `Space` 키 | 카드를 180도 플립하여 앞면 ↔ 뒷면 전환 |
| **내 명함 전환** | `←` / `→` 방향키 또는 좌우 스와이프 | 보유한 다른 명함으로 슬라이드 (끝에서 신규 명함 추가) |
| **스킨 변경** | `↑` / `↓` 방향키 또는 상하 스와이프 | 현재 명함에 다른 3D 스킨 머티리얼을 즉시 적용 |
| **명함 교환창 열기** | 하단 📷 카메라 버튼 클릭 | QR 코드 촬영 뷰파인더 및 고유 ID 입력 모달 열기 |
| **명함첩 열기** | 좌측 상단 ☰ 햄버거 메뉴 클릭 | 소속/직무별로 자동 분류된 교환 명함첩 서랍 열기 |

## 🎬 6. 3분 시연 시나리오 (Grading & Demo Scenario)

발표 및 채점 시 다음 순서로 기능을 확인하시면 가장 효과적입니다:

1. **3D 명함 인터랙션 확인**:
   - 마우스로 카드를 드래그하여 매끄러운 360도 회전과 반사광을 확인합니다.
   - 카드를 더블 클릭하여 뒷면으로 뒤집고, 적힌 Notion/GitHub 링크 칩을 눌러 웹페이지가 정상 연결되는지 확인합니다.
2. **2축 제스처 확인**:
   - 방향키 `→`를 눌러 다른 명함(대학생 명함 ↔ 프리랜서 명함)으로 전환합니다.
   - 방향키 `↓`를 눌러 홀로그램, 무광 흑요석, 네온 등의 3D 스킨을 실시간으로 변경합니다.
3. **명함 교환 기능 확인**:
   - 화면 하단의 📷 카메라 버튼을 누릅니다.
   - 카메라 뷰파인더 하단의 **[1초 테스트 QR 스캔]** 버튼을 누르거나 ID(예: `@sarah_art`)를 입력하여 명함을 수신합니다.
4. **지능형 자동 분류 명함첩 확인**:
   - 좌측 상단 햄버거(☰) 메뉴를 누릅니다.
   - 상단 탭에서 **[🏢 소속별]**과 **[💼 직무별]** 버튼을 번갈아 클릭하며, 방금 수신한 명함과 기존 명함들이 회사 및 직무별로 스마트하게 묶여 정리된 것을 확인합니다.
5. **시연 초기화**:
   - 테스트 후 데이터 초기화가 필요한 경우 햄버거 메뉴 하단의 **[시연 데이터 초기화]**를 누르면 언제든 초기 상태로 복원됩니다.

## 🛠️ 7. 기술 문의 및 트러블슈팅

- **Q. Processing에서 Run을 눌렀는데 포트 충돌 에러가 발생합니다.**  
  `CardFlip.pde`는 8080 포트가 사용 중일 경우 자동으로 8081, 8082 등으로 빈 포트를 탐색하여 자동 바인딩하므로 충돌 없이 안전하게 실행됩니다.
- **Q. 웹캠이 없거나 브라우저에서 카메라 권한이 차단되었습니다.**  
  하단 교환 모달에 내장된 **[1초 테스트 QR 스캔 시뮬레이션]** 버튼을 사용하시면 웹캠 없이도 완벽하게 교환 인터랙션을 시연할 수 있습니다.
- **Q. 인터넷이 없는 오프라인 환경에서도 실행되나요?**  
  네, Three.js 및 아이콘 라이브러리가 모두 `data/js/` 내에 로컬 포함되어 있어 인터넷 연결 없이 100% 동작합니다.
